🌦️ SkyCast - Weather Web App

SkyCast is a simple weather web app that shows the current weather conditions of any city using the AccuWeather API.

## 🔍 Features

- 🌍 Search for any city worldwide
- 🌡️ Display current temperature and weather condition
- 🌀 Real-time API data from AccuWeather
- 📱 Mobile-first responsive design (if responsive)
- ⚡ Fast and clean user interface

## 🛠️ Built With

- HTML
- CSS / Bootstrap CSS
- JavaScript (Vanilla)
- AccuWeather API
- Netlify (for deployment)
